# 本機 Revit 元件圖書館

搜尋 RFA、顯示版本與參數，瀏覽圖片與各族群類型的可旋轉／縮放 3D，並從 Revit 直接載入與放置。整合於現有 RevitMCP 外掛，不建立第二個 add-in manifest；元件庫視窗使用獨立 ExternalEvent，不依賴 MCP 連線。

## 在另一台電腦使用

1. 安裝 Node.js LTS、.NET SDK、對應年度 Revit。從本專案的單一 `MCP/RevitMCP.csproj` 建置對應年度，例如 `dotnet build -c Release.R25 MCP/RevitMCP.csproj`。
2. 使用主安裝程式，指定這台電腦的「元件」根目錄：

```powershell
./scripts/install-addon.ps1 -Version 2025 -NonInteractive -FamilyLibraryRoot 'E:\BIM\元件'
```

元件庫會安裝到目前使用者的 `%LOCALAPPDATA%\AbbyMCP\door-library`。各機的 `sources.local.json` 不進 GitHub，也不會被程式更新覆蓋。安裝不修改來源 RFA。

已安裝 Abby 自動更新的電腦可直接接收 `my-revit-tool` 的新發布版本。更新 ZIP 內含網頁程式、Three.js 與各年度 WebView2 原生載入器；更新完成後啟動 Revit，會從已驗證的發布目錄佈署網頁程式，保留設定、catalog 及私人預覽。首次尚無設定時，按「增益集 → ABBY 元件庫 → 元件圖書館」，再使用「元件路徑」選定本機根目錄。

程式更新不公開傳送 RFA 或私人 3D 資料。已匯入的可攜預覽會保留；新電腦需另外私下匯入一次預覽套件。若先前已裝獨立 ABBY 元件庫外掛，整合版會保留該註冊並重用其共用網頁，避免重複入口。

3. 重啟 Revit，在「增益集 → ABBY 元件庫 → 元件圖書館」搜尋元件，選擇族群類型，按「載入並放置」，回到專案點選位置或宿主；Esc 結束。使用工作副本載入，來源不修改。舊版族群只在專案內升級；高於目前 Revit 版本的族群不可載入。已有同名族群／類型時，提示使用專案現有版本，不自動覆寫。

發布版已對 Revit 2024、2025、2026 執行完整建置。較早年度按鈕會提示不支援。各類元件仍需符合 Revit 原生放置規則；建置與發布測試不代表每種族群都已在另一台電腦實際放置驗證。

## 路徑設定

在網頁右上角按「路徑設定」，只需填一個「元件根目錄」，再按「儲存並重新讀取」。網頁會依根目錄下既有的門、窗、職安衛與無障礙廁所分類位置讀取，不需要逐一設定分類路徑。

設定只儲存在這台電腦，儲存後立即套用，不需重啟服務，也不會修改 RFA。資料夾或元件無法讀取時保留原設定。各電腦請維持根目錄下相同的分類資料夾結構。

## 重用既有 3D 預覽

GitHub 只存程式，**不存 RFA、專案、catalog、預覽圖、3D 幾何、私人路徑或匯出日誌**。元件檔案請透過既有 OneDrive、NAS 或其他獲授權方式同步。

在已有預覽的電腦、已安裝的元件庫目錄執行：

```powershell
node portable-previews.mjs export 'E:\Transfer\family-preview-pack'
```

將預覽套件私下複製到另一台電腦，安裝時加上 `-FamilyPreviewPack 'E:\Transfer\family-preview-pack'`。也可單獨執行 `family-library/Setup-Library.ps1 -FamilyRoot ... -PreviewPack ...` 設定網頁。

新版套件另含新增來源的根目錄內相對位置及分類定義。匯入時會自動合併來源，不帶入匯出電腦的磁碟代號或 Windows 帳號，因此另一台仍只需選擇元件根目錄。純開口的示範宿主牆說明也會保留。

套件只含已匯出的圖片、幾何、必要索引與相對來源定義，不含 RFA。來源 ID、相對檔名與 SHA-256 相同才會綁定既有預覽。來源檔案變更後，清單、版本、參數與內建圖會更新，3D 標示待重新匯出。新增／變更的元件仍需用對應 Revit 年度，或另外授權的升級副本產生新 3D。

元件庫僅監聽 `127.0.0.1:4318`；不需將網頁公開到網際網路。

## 驗證

`node --test family-library/config.test.mjs` 驗證單一根目錄及可攜預覽版本範圍。`tests/abby-family-library.ps1` 驗證發布程式的雜湊、既有私人設定／預覽保留、缺檔修復、拒絕不安全項目及舊更新器的首次佈署。帶入 `-Package <發布ZIP>` 可檢查三個年度的原生載入器與網頁資源。PR 的 Windows CI 會建置完整三年度發布包，並執行更新安全、MCP 合約與 QA/QC。編譯成功不等同 Revit 實際放置驗證；請在空白測試專案先確認嵌入網頁、預覽、指定類型及宿主放置。

## 最新可攜匯入驗證

以不同元件根目錄及全新設定檔模擬另一台電腦，匯入後可讀取新增來源的 109 個元件、109 張預覽及 180 個成功的類型模型；兩個純開口類型的宿主牆標示保持一致。這是元件庫／預覽搬移驗證，不代表整合版 Revit 外掛已完成跨機放置驗證。私人預覽包與元件資料夾名稱不納入公開倉庫。
